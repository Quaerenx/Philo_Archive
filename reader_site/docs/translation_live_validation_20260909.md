- 골드셋 구조·공개 원문 정책·UTF-8 검사와 `--require-complete` 통과. `--require-passing`은 K02의 가독성, N01의 충실성·완전성·가독성, W03의 충실성 미달을 종료 코드 1로 차단한다. 미평가 항목 때문에 차단되는 것은 아니다.
