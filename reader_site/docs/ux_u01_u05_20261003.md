## 사용 방법

- Reader의 `읽기 설정`에서 `문장 선택 시 자동 번역`을 선택할 수 있다. 기본값은 꺼짐이다. 모바일에서는 학습 패널의 `본문 보기`로 패널을 접고 설정을 조작할 수 있다.
- 저장본이 없는 문장에서는 `이 문장 번역`을 누르면 새 번역을 생성한다. 이전·다음 문장 탐색, 처음 연 문장 링크, 문맥에서 문장 선택은 같은 설정을 따른다.
- 번역 목록의 `우선 검토`는 원문 연결·현재 의미 문제, 노트 문제, 자동 검토 실패·남은 모델 문제, 미확정 번역 순으로 보여준다. 같은 우선순위에서는 오래된 기록부터 보여준다. 검색·자료·작품 조건은 유지한다.
- 저장한 번역 또는 검토 목록에서 `확정 번역 수정` / `번역 직접 교정`을 열면 초안을 보관한다. 서버 내용이 바뀌면 저장을 막고 두 내용을 비교하게 한다. `최신 번역을 확인하고 편집 계속`을 선택한 뒤 다시 저장할 수 있다.
- 대시보드의 `이어 읽기`와 `최근 읽은 문서 · 4개 더 보기`로 최근 문서를 다시 연다. 같은 작품의 다른 판본은 별도 문서로 보관한다.

## 초안과 읽기 위치 보호

초안은 현재 브라우저의 `philo.reader.translationDraft.v1:<corpus>:<record-id>`에 저장한다. 필터로 행이 사라져도 보호하며, 취소한 초안은 복구할 수 있다. 저장소를 사용할 수 없으면 현재 화면에 유지하고 복사 안내를 표시한다. 저장 도중 계속 입력한 내용도 다음 편집 초안으로 남긴다.

다른 탭이 같은 초안을 바꾸면 현재 탭의 저장을 막고 복사 후 새로고침하도록 안내한다. 오래된 탭에서 번역을 원래 내용으로 되돌리는 경우에도 다른 탭의 최신 초안을 삭제하지 않도록 회귀 검사를 추가했다. 서버 저장에는 `expected_translation`을 보내 같은 저장 잠금 안에서 충돌을 확인한다. 이 필드를 생략하는 이전 클라이언트에는 해당 보호가 적용되지 않는다.

최근 문서는 `philo.reader.recentWorks.v2`에 최대 5개를 저장하며 기존 단일 문서 키도 읽고 최신 항목을 기록한다. 판본을 구분하고 문장 링크를 보존한다. 사용자의 스크롤 의도를 확인한 뒤 읽는 위치 변경을 650ms 단위로 모아 저장하고, 페이지를 벗어나거나 숨길 때 남은 위치를 즉시 저장한다. 문장 선택·링크 복원 뒤의 화면 맞춤은 저장 위치를 덮어쓰지 않는다.

## 검증과 운영 반영

- 신규 Python 검사 9개: 저장본 조회의 프롬프트·모델 호출·쓰기 방지, 확정본 우선순위, 타임존 순서, 원문·판본 경계, 원문 연결 상태, 동시 편집 충돌.
- 신규 JavaScript 검사 20항목: 현재 상태·검토 순서, 중복 제거, 최근 5문서·판본·기존 키, 초안 복구·이동 경고·저장 실패·복구 가능한 취소·저장 중 편집·다른 탭 보호, 자동 번역 설정·복원 안내, 자동 스크롤에 의한 위치 이동 방지.
- 전체 기본 `source-light` 검사, 기존 비동기 검사, 레이아웃·스크립트 의존 순서 검사 통과. 마지막 초안 보호 수정 뒤 JavaScript 20항목, Python 9개와 레이아웃 검사를 다시 통과했다.
- 실제 브라우저의 1280px·390px 화면에서 확정본, 비교 화면, 초안 편집, 검토 목록, 최근 문서와 이어 읽기를 확인했다. 확인한 화면에서 가로 넘침과 콘솔 오류가 없으며 초안 조작 버튼의 높이는 44px이다.
- 격리된 임시 저장소에서 실제 UI 저장·서버 충돌·재확인·다음 검토 항목 초점 이동을 확인했다. 세 탭을 사용해 오래된 탭이 최신 초안을 지우지 못하고 새 탭이 최신 내용을 복원하는 것도 확인했다.
- 임시 서버의 생성 파이프라인을 고정 응답으로 대체해, 기본 탐색 호출 0회와 명시적·자동 생성 각각 1회를 구분했다. 실제 모델을 호출하지 않은 흐름 검증이다.
- 실제 서비스의 저장본 조회 성공·미저장 조회 모두 요청별 모델 호출 0회였다. 운영 번역 211개와 보호 파일 9개(번역·노트·승인 프로필·골드셋·원문 검사·평가 장부)의 SHA-256을 보존했다.
- Reader에 서버 변경을 반영했으며 공유 Gemma 프로세스는 유지했다. 최종 Reader·Gemma 상태 확인이 정상이다.

검토 목록에는 확인 시점에 114개 문장이 있었다. 이 숫자에는 원문 연결이 확인되지 않는 과거 기록과 아직 사람이 확정하지 않은 번역도 포함된다. 실제 언어 품질을 다시 평가한 결과는 아니다.

실제 터치 기기, 장시간 사용, 모든 문서·설정 조합, 새 Gemma 번역의 언어 품질은 검증하지 않았다. 미저장 이동 경고는 자동 검사로 확인했으며 실제 브라우저의 이동 확인 대화상자는 수동 검증하지 않았다. 초안·읽기 위치는 현재 브라우저에서 보관한다.
