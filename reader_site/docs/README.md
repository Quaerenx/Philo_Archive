# Current Documentation

This directory contains only documents that describe the current reader, its operating procedures, or enforced contracts.

## Operation

- `local_operator_quickstart.md`: daily startup and runtime troubleshooting.
- `local_windows_autostart.md`: optional Windows startup registration.
- `api_reference.md`: current HTTP API contract.

## Data And Policy

- `corpus_schema.md`: shared corpus, work, variant, and segment schema.
- `corpus_display_policy.md`: reader labels, variant order, and default representation policy.
- `ai_interpretation_policy.md`: source-boundary, provenance, storage, and UI rules for local AI output.
- `encoding_policy.md`: UTF-8 and Korean source-root naming policy.
- `source_publication_policy.md`: boundary between tracked application metadata and local primary-source data.
- `search_quality_policy.md`: benchmark and privacy-preserving research-question evaluation policy.

## Reproducibility And Release

- `clean_clone_reproducibility.md`: source-light clone and full local restore workflow.
- `release_handoff.md`: release contents, exclusions, and validation commands.

Superseded roadmaps, completed execution prompts/reviews, historical handoff notes, and dated validation receipts are preserved in [`OLD`](../../OLD/README.md). They are evidence of earlier work, not current operating instructions.
